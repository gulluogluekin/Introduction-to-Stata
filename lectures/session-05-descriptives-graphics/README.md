# Session 5: Descriptive analysis and graphics

Date: 12 October 2026

## Learning goals

- Match descriptive statistics to variable types and analytic questions.
- Build grouped summaries and export a machine-readable table.
- Select a graph for a distribution, comparison, or relationship.
- Label and export graphics so they can be interpreted outside Stata.

## Files

- `lecture.do`: creates descriptive tables and three complementary figures.
- `exercise.do`: checkpoint requiring a table and two student-designed figures.

## Checkpoint

Submit the do-file and two PNG figures. A figure must communicate a specific comparison or
relationship; decorative output without a clear question does not satisfy the checkpoint.
