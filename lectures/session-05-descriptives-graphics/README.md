# Session 5: Descriptive analysis and hotel-price graphics

Date: 12 October 2026

## Learning goals

- Match descriptive statistics to variable types and questions.
- Compare hotel prices across cities and star categories.
- Export a reproducible grouped table.
- Create distribution, group-comparison, and relationship graphs.
- Use titles, axes, units, and notes to make graphics interpretable.

## Checkpoint

Export one grouped summary table and two purposeful figures based on the hotel panel. Each
figure must communicate a specific comparison or relationship rather than decorate output.
