# Session 4: Programming repeated hotel analyses

Date: 5 October 2026

Assessment: individual checkpoint 3 of 4, worth 10% of the overall course grade.

## Learning goals

- Store variable names and labels in local macros.
- Loop over variables and cities only when work is genuinely repeated.
- Use conditions based on data and stored results.
- Write and call a small `rclass` summary program.
- Inspect returned results rather than copying output by hand.

## Graded checkpoint 3

Allow about 20 minutes. The lecture loops over variables, cities, and years and returns
N, mean, and median. The exercise transfers these patterns to a new question: how does
measured price variability change when the upper price cutoff changes?

- Consult `help summarize` to find standard deviation and quartile return values.
- Adapt the lecture's `rclass` program to return N, standard deviation, and interquartile
  range (the 75th percentile minus the 25th percentile).
- Loop over upper price cutoffs of EUR 100, 200, and 500 without permanently filtering
  the data, and check one result against a direct summary.
- Test a variable with missing values and an empty sample, then explain the sample
  sensitivity in comments. Summary observation counts refer to quotes, not unique hotels.

Run `exercise.do` from the project root. It needs `data/derived/hotel_panel.dta`, supplied
by the instructor or generated by the preparation and analysis scripts. Reuse the lecture's
program structure, but use a distinct program name (`hotel_spread`) and adapt the returned
statistics and sample conditions. No new data preparation is required.

Submit the completed do-file and `output/logs/session04_exercise.log`, including the checks
and short interpretation. The starter creates this separate log and runs before the TODOs
are completed, but does not contain their solutions.
