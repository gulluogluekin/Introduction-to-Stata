# Notice

This repository contains original course materials for ECBS5241 Introduction to Stata at
Central European University.

The hotel datasets were prepared for:

Békés, Gábor, and Gábor Kézdi. 2021. *Data Analysis for Business, Economics, and Policy*.
Cambridge University Press.

Dataset-specific attribution and reuse terms appear in `DATA_LICENSE.md`.

The curriculum was also informed by an earlier Stata example in the public
`ulrichwohak/coding_for_economists` repository and by the historical CEU ECBS5241 course
description. All course code has been rewritten for the 2026–2027 pure-Stata course.
